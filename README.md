# Kalyan Jewellers Clone

I vibe coded it just for fun to see if I can actually make it. 

---

## Overview
A fully responsive, modern web application designed to recreate the luxurious, premium experience of Kalyan Jewellers. Built from scratch with a focus on stunning UI, smooth animations, and high-quality interactive product displays.

## ✨ Features
- **Interactive 3D Tilt Cards:** Beautiful, engaging product displays that react to user interaction.
- **Velocity Loading Screen:** A premium scrolling marque loading experience featuring custom models.
- **Responsive Design:** Optimized to look incredible on desktop, tablet, and mobile devices.
- **Custom UI Components:** Fluid animations and layouts built using modern frontend tools.

## 🛠️ Tech Stack
- React (Vite)
- Tailwind CSS
- Framer Motion
- Lucide Icons
